## JSDC2024 講者公布 📣📣 - Kevin Hu

![Kevin-JSDC2024](https://i.imgur.com/8otttJA.png)

▍Kevin Hu | Olio 前端工程師 & React Native 技術專家

═ React Native 朝聖之路 ═

### 關於講者 #ReactNative #JavaScript #Frontend

Kevin Hu 目前於倫敦新創 Olio 擔任前端工程師，曾在新加坡蝦皮任職，專注於前端技術開發。身為 React Native 愛好者，長期投入該領域並持續深耕，對其生態系有豐富的實務經驗與洞察。

在 JSDC 2024 中，Kevin 將分享他走訪世界各地 React Native 大型研討會的經驗，包括 Chain React、React Advanced、React Native EU、App.js Conf 以及 React Native London Conf 的所見所聞。他期望能將 React Native 的前沿資訊與觀察帶回台灣，與大家分享並回饋社群。這個議題特別適合所有對 React Native 開發感興趣以及想了解國際開發趨勢的開發者。

機會有限，錯過不在。馬上購票行動，到 JSDC 主年會購票。

## Kevin Hu, JSDC2024 Speaker Announcement 📣📣

![Kevin-JSDC2024](https://i.imgur.com/8otttJA.png)

▍Kevin Hu | Frontend Engineer at Olio & React Native Expert

═ A Pilgrimage Through the React Native World ═

### About the Speaker #ReactNative #JavaScript #Frontend

Kevin Hu is currently a frontend engineer at Olio, a London-based startup, and previously worked at Shopee in Singapore. As a React Native enthusiast, he has deeply invested in the field and has extensive practical experience and insights into its ecosystem.

At JSDC 2024, Kevin will share his experiences from attending major React Native conferences worldwide, including Chain React, React Advanced, React Native EU, App.js Conf, and React Native London Conf. He aims to bring cutting-edge React Native insights and observations back to Taiwan, sharing with the community and contributing to its growth. This topic is particularly relevant for developers interested in React Native development and international development trends.
