## JSDC2024 講者公布 📣📣 - 戴均民

![Chunmin-JSDC2024](https://i.imgur.com/yNtU9au.png)

▍戴均民 | 車能網資訊股份有限公司 後端工程師

═ 用網頁的 Web Serial 及 Web Bluetooth 控制你的嵌入式設備 ═

### 關於講者 #IoT #JavaScript #WebSerial #WebBluetooth

戴均民是一位來自台中、現居台北的網站後端工程師。他對 LINE Chatbot、RFID 和量化交易等技術領域有濃厚興趣。在嵌入式設備開發方面擁有豐富經驗，特別專注於 Web 技術與硬體整合的創新應用。

在 JSDC 2024 中，戴均民將分享如何運用 Web Bluetooth API 和 Web Serial API 來開發跨平台的圖形化介面。這些技術讓前端工程師能夠輕鬆地為嵌入式設備開發支援多平台的應用程式，包括 Windows、Mac、Linux、Android 和 iOS。透過特定瀏覽器，使用者可以直接通過網頁介面控制嵌入式設備，大幅簡化了開發和使用流程。

## Chunmin Tai, JSDC2024 Speaker Announcement 📣📣

![Chunmin-JSDC2024](https://i.imgur.com/yNtU9au.png)

▍Chunmin Tai | Backend Engineer at Parking Lot Network Information Co., Ltd.

═ Controlling Embedded Devices with Web Serial and Web Bluetooth ═

### About the Speaker #IoT #JavaScript #WebSerial #WebBluetooth

Chunmin Tai is a backend engineer based in Taipei, originally from Taichung. He has keen interests in LINE Chatbot, RFID, and quantitative trading. With extensive experience in embedded systems development, he specializes in integrating Web technologies with hardware applications.

At JSDC 2024, Chunmin will demonstrate how to leverage Web Bluetooth API and Web Serial API to develop cross-platform graphical interfaces. These technologies enable frontend developers to easily create multi-platform applications for embedded devices, supporting Windows, Mac, Linux, Android, and iOS. Users can control embedded devices directly through web interfaces using specific browsers, significantly simplifying both development and user experience.
